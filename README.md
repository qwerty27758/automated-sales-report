# Automated Sales Analytics Report

Автоматизированный аналитический отчёт по продажам на Python.

Проект получает данные через REST API, обрабатывает их с помощью Pandas, рассчитывает ключевые показатели, формирует Excel-отчёт с дашбордом и автоматически отправляет результаты в Telegram.

## Возможности

- получение данных через REST API;
- обработка данных с помощью Pandas;
- расчёт выручки, расходов и прибыли;
- расчёт маржи;
- определение убыточных заказов;
- поиск самого убыточного заказа;
- формирование Excel-отчёта;
- создание аналитического дашборда;
- форматирование Excel-файла с помощью OpenPyXL;
- отправка краткой сводки в Telegram;
- отправка готового Excel-файла в Telegram;
- автоматический запуск по расписанию через Windows Task Scheduler.

## Технологии

- Python
- Pandas
- Requests
- OpenPyXL
- python-dotenv
- REST API
- Telegram Bot API
- Excel
- Windows Task Scheduler

## Схема работы

```text
REST API
   ↓
Requests
   ↓
Pandas DataFrame
   ↓
Расчёт показателей
   ↓
Excel + Dashboard
   ↓
Telegram Bot API
   ↓
Сообщение + Excel-файл
```

## Основные показатели

Проект рассчитывает:

- общую выручку;
- общие расходы;
- общую прибыль;
- общую маржу;
- количество убыточных заказов;
- самый убыточный заказ.

## Excel-отчёт

В результате работы создаётся файл:

```text
sales_report.xlsx
```

В нём находятся:

- **Все заказы** — полный набор данных;
- **Убыточные заказы** — заказы с отрицательной прибылью;
- **Итоги** — основные показатели;
- **Дашборд** — визуальное представление KPI и графиков.

## Telegram

После формирования отчёта бот автоматически отправляет:

1. краткую аналитическую сводку;
2. готовый Excel-файл.

Пример сообщения:

```text
📊 Отчёт по продажам

💰 Выручка: 3,100,589 ₽
💸 Расходы: 2,202,339 ₽
📈 Прибыль: 898,250 ₽
📊 Общая маржа: 28.97%
⚠️ Убыточных заказов: 38

🔻 Самый убыточный заказ: №11
Прибыль: -36,560 ₽
```

## Автоматизация

Для автоматического запуска используется стандартный **Windows Task Scheduler**.

Например:

```text
09:00
  ↓
Windows Task Scheduler
  ↓
Python
  ↓
sales_project.py
  ↓
Формирование отчёта
  ↓
Отправка в Telegram
  ↓
Завершение программы
```

Python не требуется держать постоянно запущенным в терминале.

## Установка

Клонировать репозиторий:

```bash
git clone <URL_репозитория>
cd ai_data_project
```

Установить зависимости:

```bash
pip install -r requirements.txt
```

## Настройка Telegram

Создайте Telegram-бота через `@BotFather`.

В корне проекта создайте файл:

```text
.env
```

и добавьте:

```text
TELEGRAM_TOKEN=your_telegram_bot_token
CHAT_ID=your_chat_id
```

Файл `.env` содержит секретные данные и не должен публиковаться в GitHub.

Для примера конфигурации используется файл:

```text
.env.example
```

## Запуск

После настройки `.env`:

```bash
python sales_project.py
```

После запуска программа:

1. получает данные;
2. выполняет расчёты;
3. создаёт Excel-отчёт;
4. отправляет сводку в Telegram;
5. отправляет Excel-файл в Telegram;
6. завершает работу.

## Безопасность

Секретные данные Telegram не хранятся непосредственно в исходном коде.

Используется:

```text
.env
```

а файл `.env` добавлен в:

```text
.gitignore
```

Таким образом, Telegram-токен не попадает в Git-репозиторий.
